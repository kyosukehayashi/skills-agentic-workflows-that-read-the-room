## Recent GitHub updates

### Wait for pull request events with GitHub CLI

GitHub CLI can wait for pull request activity with `gh event listen`, including
submitted reviews, state changes, and completed check suites. This gives scripts
and coding agents an alternative to repeatedly checking for updates.

The commands are in preview. They require GitHub CLI v2.105.0 or later and access
to the GitHub Event Streams preview, so check availability before adopting them.

Source: [GitHub Changelog, November 18, 2026](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli/).
